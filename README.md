# Мини-розница на 1С:Предприятие 8.3 + Telegram

Учебная конфигурация розничного магазина на платформе 1С:Предприятие 8.3: учёт поступлений и продаж, остатки с контролем, уведомления о продажах в Telegram и автотест.

## Что умеет

**Учёт товаров**
- `ПоступлениеТовара` проводится приходом в регистр накопления `ОстаткиТоваров`
- `ПродажаТовара` проводится расходом и **не даёт продать больше, чем есть на складе**: при нехватке документ не проводится, пользователь видит «Не хватает товара "Кофе": 7 шт.»
- остатки на время проведения блокируются управляемой блокировкой, чтобы два кассира не продали один и тот же последний товар
- суммы строк и итог пересчитываются в модуле объекта (`ПередЗаписью`), поэтому они верны, даже если документ записан кодом, а не из формы

**Уведомления в Telegram**
- после проведения продажи из формы в Telegram уходит сообщение: номер, сумма, клиент и список товаров
- отправка через Bot API (`HTTPСоединение`, JSON), ошибки пишутся в журнал регистрации и не мешают работе кассира
- токен бота и ID чата хранятся в константах базы, **в исходниках их нет**

**Автотест**
- общий модуль `Самопроверка` создаёт демо-данные, проводит поступление и продажу, проверяет суммы, контроль остатков и отправку в Telegram
- запускается из командной строки, результат пишется в файл:

```
1cv8 ENTERPRISE /F "<база>" /C "autotest;out=C:\temp\autotest.txt"
```

```
RESULT: PASSED
OK  Поступление проведено: кофе 5, чай 3
OK  Продажа проведена на 1 200 руб.
OK  Продажа сверх остатка не провелась (контроль остатков работает)
OK  Остатки изменились верно: кофе +3, чай +2
OK  Уведомление о продаже отправлено в Telegram
```

## Структура

| Объект | Назначение |
|---|---|
| `Справочник.Товары` | товары и цена по умолчанию |
| `Справочник.Клиенты` | клиенты и телефон |
| `Документ.ПоступлениеТовара` | приход товара на склад |
| `Документ.ПродажаТовара` | продажа, контроль остатков, уведомление в Telegram |
| `РегистрНакопления.ОстаткиТоваров` | остатки товаров (вид: остатки) |
| `Константа.ТелеграмТокенБота`, `Константа.ТелеграмЧатИД` | настройки Telegram |
| `ОбщийМодуль.ТелеграмСервер` | отправка сообщений через Bot API |
| `ОбщийМодуль.Самопроверка` | автотест и сохранение настроек |

## Как запустить

1. Создайте пустую файловую информационную базу.
2. В Конфигураторе: *Конфигурация → Загрузить конфигурацию из файлов*, папка `src`, затем *Обновить конфигурацию базы данных* (F7).
3. Сохраните настройки Telegram (или заполните константы вручную):

```
1cv8 ENTERPRISE /F "<база>" /C "settings;token=<токен бота>;chat=<ID чата>"
```

Платформа: 1С:Предприятие 8.3.27.
