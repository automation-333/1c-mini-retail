# Мини-розница на 1С:Предприятие 8.3

Учебная конфигурация розничного магазина на платформе 1С:Предприятие 8.3. Развиваю её по шагам: от справочников и документов к проведению, регистрам, запросам, отчётам на СКД и интеграции с Telegram.

## Что уже есть

**Справочники**
- `Товары`: реквизит `Цена`
- `Клиенты`: реквизит `Телефон`

**Документы**
- `ПродажаТовара`: клиент, табличная часть `Товары` (товар, количество, цена, сумма), итог `СуммаДокумента`

**Форма документа** (`Documents/ПродажаТовара/Forms/ФормаДокумента`)
- при выборе товара цена подставляется из справочника серверным вызовом `&НаСервереБезКонтекста`
- сумма строки и итог документа пересчитываются на клиенте при изменении количества, цены и удалении строк

## Как открыть

Исходники выгружены через Конфигуратор: *Конфигурация → Выгрузить конфигурацию в файлы*.

Чтобы загрузить в свою базу: создайте пустую информационную базу, откройте Конфигуратор и выберите *Конфигурация → Загрузить конфигурацию из файлов*, указав папку `src`.

Платформа: 1С:Предприятие 8.3.27.
